What I’m Working On

HardwareMon

HardwareMon is a modern cross-platform hardware monitoring platform built with Flutter and FastAPI.

The project delivers real-time system telemetry through a cinematic desktop experience, featuring live CPU, RAM, GPU, temperature, power, and process monitoring. It is distributed through automated CI/CD pipelines and includes Linux package repositories, Windows installer deployment, and cloud-hosted infrastructure.

Future development is focused on historical analytics, remote monitoring, plugin support, and expanding the HardwareMon ecosystem across additional platforms.
